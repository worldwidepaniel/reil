# Pracownia Pszczelarska REIL

## Colors available to use

- oklch(33.4% 0.023 77.8) -> taupe
- oklch(81.2% 0.152 74.2) -> honey bronze
  Remember about 60/30/10 rule. You can swap colors % between dark and light mode i.e light mode more honey and dark mode more taupe

## Requirements

- Good lighthouse results
- i18n (Polish and English with Polish being the main language -- off which all other translations are based upon)
- Wow effect
- bold typography
- gsap + threejs use
- WCAG AAA and reduced motion support
